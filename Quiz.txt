1️⃣ Τι επιστρέφει η malloc;

A) Δείκτη σε τύπο int
B) Δείκτη τύπου void* ✅
C) Μέγεθος σε bytes της μνήμης που δεσμεύτηκε
D) Λογική τιμή true ή false

Σωστή: B

2️⃣ Ποια διαφορά έχει η calloc από τη malloc;

A) Η calloc δεσμεύει μνήμη για έναν μόνο ακέραιο
B) Η calloc αρχικοποιεί τη μνήμη με μηδενικά ✅
C) Η calloc δε χρειάζεται free()
D) Δεν υπάρχει διαφορά

Σωστή: B

3️⃣ Ποιο είναι το σωστό για να επεκτείνεις έναν πίνακα arr σε C;

A) arr = malloc(new_size * sizeof(int));
B) arr = calloc(new_size, sizeof(int));
C) arr = realloc(arr, new_size * sizeof(int)); ✅
D) arr = free(arr);

Σωστή: C

4️⃣ Τι συμβαίνει αν κάνουμε realloc(ptr, 0);;

A) Δεσμεύεται περισσότερη μνήμη
B) Απελευθερώνεται η μνήμη και επιστρέφεται NULL ✅
C) Το πρόγραμμα πετάει runtime error
D) Η μνήμη παραμένει αμετάβλητη

Σωστή: B

5️⃣ Ποιο είναι το σωστό για δείκτη σε δείκτη;
int x = 10;
int *p = &x;
int **pp = &p;


A) *p δείχνει στον x ✅
B) **pp δείχνει στη διεύθυνση του p
C) *pp δείχνει στον x
D) pp δείχνει στον x

Σωστή: A
